# Sistema-E-Commerce

Projeto desenvolvido durante o curso de SQL da DIO (Digital Innovation One), ministrado pela professora Juliana Mascarenhas, utilizando o MySQL Workbench. A partir da estrutura inicial apresentada nas aulas, realizei adaptações na modelagem do banco de dados, inseri dados fictícios para testes e desenvolvi as consultas SQL propostas, além de consultas adicionais criadas por mim para aprofundar o aprendizado e demonstrar a aplicação dos conceitos estudados. 

O projeto deve ser executado na seguinte sequência: schema -> inserts -> queries.

As perguntas de negócio utilizadas para desenvolver as queries foram:
- Quantos pedidos foram feitos por cada cliente?
- Algum vendedor também é fornecedor?
- Relação entre produtos, fornecedores e estoques.
- Identificação dos clientes que realizaram mais de um pedido.
- Quais clientes já tiveram pelo menos um pedido confirmado?
- Quais produtos custam mais de R$ 100,00?
- Qual é a média de preço por categoria?
- Quais fornecedores fornecem produtos eletrônicos?
- Classificação dos produtos por faixa de preço.
- Quais são os produtos mais caros?
- Qual a quantidade de cada produto e o total armazenado em cada estoque?
