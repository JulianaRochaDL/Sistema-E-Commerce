# Sistema-E-Commerce

Projeto desenvolvido durante o curso de SQL da DIO (Digital Innovation One), ministrado pela professora Juliana Mascarenhas. A partir da estrutura inicial apresentada nas aulas, realizei adaptações na modelagem do banco de dados, inseri dados fictícios para testes e desenvolvi as consultas SQL propostas, além de consultas adicionais criadas por mim para aprofundar o aprendizado e demonstrar a aplicação dos conceitos estudados.
